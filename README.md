Welcome to my **Windows 10 STIG Hardening Portfolio** — a hands-on collection of remediations and security configurations designed to strengthen Windows 10 environments against real-world threats and meet strict compliance requirements.

This project showcases my ability to:

✅ Automate and apply security hardening  
✅ Document remediation workflows clearly  
✅ Validate and verify system compliance  
✅ Translate STIG controls into actionable configurations  
✅ Operate in a methodical, audit-friendly manner

Each STIG in this portfolio was carefully implemented and tested in my personal lab environment — providing measurable security improvements while aligning with **NIST 800-53** and **DoD STIG** requirements.

---

## 📁 Portfolio Structure

Each STIG folder includes:

- 🔎 **STIG Description & ID**  
- 🛠️ **Remediation Steps** (PowerShell, GPO, or manual config)  
- 🖥️ **Configuration Scripts** (where applicable)  
- ✅ **Verification Steps**  
- 📊 **Supporting Documentation or References**
