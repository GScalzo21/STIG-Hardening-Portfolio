# ✅ STIG Remediation: WN10-CC-000105

## 🔐 Title  
**Disable Internet Download for Web Publishing and Online Ordering Wizards**

## 📋 Description  
To reduce the risk of downloading potentially malicious content, Windows systems must block Internet downloads initiated by legacy wizards like Web Publishing and Online Ordering. These features are rarely used in modern enterprise environments and can introduce unnecessary exposure to external sources.

## 🛠️ Remediation  
Configure the following Group Policy setting:

**Path:**  
`Computer Configuration >> Administrative Templates >> System >> Internet Communication Management >> Internet Communication settings`

**Setting:**  
`Turn off Internet download for Web publishing and online ordering wizards` → **Enabled**

## 🔎 Validation  

To verify this policy has been applied:

1. Open **Local Group Policy Editor** (`gpedit.msc`)
2. Navigate to the specified path
3. Confirm the setting is set to **Enabled**

Alternatively, check via PowerShell:

```powershell
Get-ItemProperty -Path "HKLM:\Software\Policies\Microsoft\Windows\Internet Management\Internet Communication" | Select DisableWebPublishingWizard
```
# ✅ Expected Output

```powershell
DisableWebPublishingWizard : 1
```

## 📌 Notes

Disabling this feature helps reduce unnecessary Internet communication from the system and minimizes exposure to legacy components that may not align with modern security standards.
