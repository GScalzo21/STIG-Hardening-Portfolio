# 🔒 STIG Remediation: WN10-CC-000270

**STIG ID:** WN10-CC-000270  
**Title:** Passwords must not be saved in the Remote Desktop Client  
**Severity:** Medium  
**Rule Version:** V1R20  
**Finding ID:** V-220695

---

## 📋 Description

Saving passwords in the Remote Desktop Connection client increases the risk of credential theft. Enabling this policy ensures that users are always required to re-enter their passwords when using Remote Desktop, reducing the chance of unauthorized access.

---

## 🧰 Remediation Steps (Group Policy)

1. Press `Windows Key + R`, type `gpedit.msc`, and press Enter to launch the **Local Group Policy Editor**.
2. Navigate to:
   ```
   Computer Configuration
   └── Administrative Templates
       └── Windows Components
           └── Remote Desktop Services
               └── Remote Desktop Connection Client
   ```
3. Double-click on **Do not allow passwords to be saved**.
4. Set the policy to **Enabled**.
5. Click **Apply**, then **OK**.

---

## 💻 Remediation via PowerShell (Registry Edit)

```powershell
# Ensure the policy path exists
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" -Force

# Set the registry key to prevent saving passwords
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" -Name "DisablePasswordSaving" -Type DWord -Value 1
```

---

## ✅ Verification

To confirm the setting is applied, run:

```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" | Select-Object DisablePasswordSaving
```

Expected Output:
```
DisablePasswordSaving : 1
```
