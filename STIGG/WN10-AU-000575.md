## ⚠️ Notice: Audit Deprecated

This audit category has been **deprecated** and is expected to be removed in future Windows 10 updates.  
However, systems should still be configured accordingly if the option is available to maintain **legacy compliance** until officially retired.

---

## 🔍 Finding

Auditing **MPSSVC Rule-Level Policy Changes** helps track changes to rules that affect the **Microsoft Protection Service (MPSSVC.exe)**.  

This can be useful for detecting **unauthorized or unintended modifications** to:

- **System firewall policies**  
- Other **rule-based configurations** impacting system protection

---

## 🛠️ Manual Configuration

### Open Local Group Policy Editor:

- Press `Win + R`, type `gpedit.msc`, and press **Enter**.

### Navigate to:

```text
Computer Configuration
└─ Windows Settings
   └─ Security Settings
      └─ Advanced Audit Policy Configuration
         └─ System Audit Policies
            └─ Policy Change
```
## 🛠️ Configure the Following Setting

1. Locate and double-click:  
   **Audit MPSSVC Rule-Level Policy Change**

2. Check the box for:  
   ✅ **Success**

3. Click **Apply**, then **OK**
