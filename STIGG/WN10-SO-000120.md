# 🔐 STIG ID: WN10-SO-000120  
**Title:** SMB Server Must Always Perform Packet Signing

---

## ✅ Finding  
The system was not configured to enforce SMB packet signing, which is required to help prevent man-in-the-middle (MITM) attacks on SMB communications.

---

## 🛠️ Remediation Steps  
1. Open the **Local Group Policy Editor** by running `gpedit.msc`.
2. Navigate to the following path:  
   `Computer Configuration` → `Windows Settings` → `Security Settings` → `Local Policies` → `Security Options`
3. Find the policy:  
   **Microsoft network server: Digitally sign communications (always)**
4. Set the policy to: **Enabled**
5. Close the Group Policy Editor.
6. Run the following in **Command Prompt** to apply changes immediately:

   ```cmd
   gpupdate /force

## 🔎 Validation & 📌 Notes

To verify the setting was applied correctly:

1. Open **PowerShell** as Administrator  
2. Run the following command:

   ```powershell
   Get-SmbServerConfiguration | Select EnableSecuritySignature
