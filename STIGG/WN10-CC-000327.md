# **WN10-CC-000327 - PowerShell Transcription must be enabled on Windows 10**

**Audit Deprecated Warning**:  
This audit is deprecated and will be removed in a future update. Despite this, enabling PowerShell transcription is still a good security practice for ensuring audit trails are available in the event of a security incident.

---

## **Information**

PowerShell transcription captures detailed logs of PowerShell commands and scripts that are executed on the system. This helps in:
- Identifying configuration errors.
- Troubleshooting service disruptions.
- Analyzing potential system compromises.
- Detecting unexpected or malicious behavior.

By enabling transcription, you'll have a record of what commands were executed and help track down activities in case of a breach.

---

## **Solution**

Follow these steps to enable **PowerShell Transcription**:

### **Step 1: Open the Group Policy Editor**

1. Press `Windows + R` to open the Run dialog.
2. Type `gpedit.msc` and press **Enter** to open the **Local Group Policy Editor**.

### **Step 2: Configure the PowerShell Transcription Policy**

1. In the Group Policy Editor, navigate to:
    ```
    Computer Configuration
    >> Administrative Templates
    >> Windows Components
    >> Windows PowerShell
    ```

2. Find the setting named **Turn on PowerShell Transcription**.

3. Double-click on this setting, and in the dialog box that opens, select **Enabled**.

4. Under **Options**, you can specify the **Transcript output directory**. It's highly recommended to set this to a **Central Log Server** or another secure location to prevent user access to these logs. For example, you can set the directory to something like:
    ```
    \\ServerName\PowerShellLogs
    ```

5. Click **OK** to apply the policy.

### **Step 3: Verify Configuration**

To ensure PowerShell transcription is enabled:

1. Open **PowerShell** as an administrator.
2. Run the following command to verify if transcription is active:
    ```powershell
    Get-ItemProperty -Path "HKLM:\Software\Policies\Microsoft\Windows\PowerShell" -Name "EnableTranscripting"
    ```

3. If transcription is enabled, the result should show that **EnableTranscripting** is set to **1**.

---

## **PowerShell Alternative: Enabling via PowerShell Command**

If you prefer to use PowerShell directly, you can enable transcription with the following command:

```powershell
Set-ItemProperty -Path "HKLM:\Software\Policies\Microsoft\Windows\PowerShell" -Name "EnableTranscripting" -Value 1


Optional: Set Transcript Output Directory via PowerShell
You can also specify the transcript output directory directly from PowerShell:

Set-ItemProperty -Path "HKLM:\Software\Policies\Microsoft\Windows\PowerShell" -Name "TranscriptionOutputDirectory" -Value "\\ServerName\PowerShellLogs"
