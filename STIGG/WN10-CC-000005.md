# Remediation for STIG ID: WN10-CC-000005

## Title:
Disable Camera Access from Lock Screen

## Description:
The camera must not be accessible from the lock screen to prevent unauthorized use or exploitation of device hardware when the device is locked.

## Remediation Steps (Using Local Group Policy):

1. Press `Windows + R`, type `gpedit.msc`, and press Enter.
2. Navigate to:


Computer Configuration > Administrative Templates > Control Panel > Personalization


3. Locate the policy:
**"Prevent enabling lock screen camera"**
4. Set the policy to:
**Enabled**
5. Click **Apply**, then **OK**.

## Notes:
This ensures that no camera access is permitted from the lock screen, helping protect user privacy and data.
