# 🔒 STIG Remediation: WN10-CC-000280

**Title:** Remote Desktop Services must always prompt a client for passwords upon connection  
**Severity:** Medium  
**Status:** ✅ Compliant (if properly configured)  
**Audit Status:** Manual Check  
**STIG ID:** WN10-CC-000280  
**Vuln ID:** V-220823  
**SRG ID:** SRG-OS-000373-GPOS-00156  
**CCI:** CCI-002038  

---

## 🔍 Finding

By default, **Remote Desktop Services (RDS)** can allow credentials to be **saved by the client**.  
This could enable a user to gain **unauthorized access** without re-authentication.  

Enforcing the **password prompt** ensures users must manually authenticate upon each **Remote Desktop session**, enhancing security and reducing the risk of compromised **saved credentials**.

---

## 🛠️ Manual Configuration

### Open Local Group Policy Editor

- Press `Win + R`, type `gpedit.msc`, press **Enter**.

---

### Navigate to:

```text
Computer Configuration
└─ Administrative Templates
   └─ Windows Components
      └─ Remote Desktop Services
         └─ Remote Desktop Session Host
            └─ Security
```

## 🛠️ Configure the Following Setting

- Double-click: **Always prompt for password upon connection**.
- Set the policy to: ✅ **Enabled**.
- Click **Apply**, then **OK**.

---
