# WN10-00-000031: Require BitLocker PIN for Pre‑Boot Authentication

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Unencrypted data at rest can be read directly if an adversary has physical access. BitLocker encryption protects data confidentiality, and requiring a pre‑boot PIN with TPM ensures only authorized users can unlock the OS drive before Windows loads.

## Solution  
Enable additional startup authentication with a PIN (with TPM) by configuring the following policy:


- **Configure TPM Startup PIN:** Require startup PIN with TPM  
**OR**  
- **Configure TPM Startup Key and PIN:** Require startup key and PIN with TPM

---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to BitLocker OS Drive Settings**  
   - Expand:
     ```text
     Computer Configuration
     └─ Administrative Templates
        └─ Windows Components
           └─ BitLocker Drive Encryption
              └─ Operating System Drives
     ```

3. **Locate “Require additional authentication at startup”**  
   - Select the policy named **Require additional authentication at startup**.

4. **Enable and Configure the Policy**  
   - Double‑click the policy.  
   - Select **Enabled**.  
   - Under **Options**, choose one of the following:
     - **Require startup PIN with TPM**  
       (Select **Configure TPM startup PIN** → **Require startup PIN with TPM**)  
     - **Require startup key and PIN with TPM**  
       (Select **Configure TPM startup key and PIN** → **Require startup key and PIN with TPM**)  
   - Click **OK**.

5. **Apply and Refresh**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

6. **Configure BitLocker on Target Machines**  
   - Open an elevated PowerShell prompt and run:
     ```powershell
     Enable-BitLocker -MountPoint "C:" -TpmProtector -PinProtector
     ```
   - When prompted, enter the desired startup PIN.

7. **Verify Configuration**  
   - Check BitLocker status:
     ```powershell
     Get-BitLockerVolume -MountPoint "C:" | Select-Object VolumeStatus, KeyProtector
     ```
   - Confirm that a TPM + PIN protector is present.

---

## Summary of Steps

1. **gpedit.msc** → Administrative Templates → Windows Components → BitLocker Drive Encryption → Operating System Drives  
2. **Enable** “Require additional authentication at startup”  
3. **Select** TPM + PIN (or TPM + Key & PIN)  
4. **gpupdate /force**  
5. **Enable‑BitLocker** with `-TpmProtector -PinProtector`  
6. **Verify** protector configuration
