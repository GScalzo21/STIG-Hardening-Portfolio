# 🔌 STIG Remediation: WN10-CC-000180  
**Title:** Autoplay Must Be Turned Off for Non-Volume Devices  
**Severity:** Medium  
**Status:** ✅ Compliant  
**Audit Status:** Manual Check  
**STIG ID:** WN10-CC-000180  
**Vuln ID:** V-220926  
**SRG ID:** SRG-OS-000370-GPOS-00155  
**CCI:** CCI-001958  

---

## 🔍 Finding

Autoplay on non-volume devices (e.g., cameras, phones, or streaming devices) can allow the automatic execution of untrusted content, increasing the attack surface for malware and unauthorized code execution.

This policy disables Autoplay for **non-volume devices**, adding another layer of defense against removable media threats.

---

## 🛠️ Remediation Steps

1. Press `Win + R`, type `gpedit.msc`, and press **Enter**.
2. In the **Local Group Policy Editor**, navigate to:

Computer Configuration >>
Administrative Templates >>
Windows Components >>
AutoPlay Policies

3. Double-click **Turn off Autoplay for non-volume devices**.
4. Set the policy to **Enabled**.
5. Click **Apply**, then **OK**.

---

## ✅ Verification

To verify the setting:
1. Reopen the **Group Policy Editor**.
2. Return to:

AutoPlay Policies >> Turn off Autoplay for non-volume devices

3. Confirm the setting is **Enabled**.

---

## 🧪 Optional PowerShell Check

You can query this setting in the registry:
```powershell
Get-ItemProperty -Path "HKLM:\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer" -Name "NoAutoplayfornonVolume"
```
Expected Value:

NoAutoplayfornonVolume : 1

🔁 Reboot Required?

❌ Not required
✅ Run the following to enforce policy immediately:
gpupdate /force

📌 Notes

This setting is different from the general Turn off Autoplay policy, which affects volume devices like USB drives.
This applies to devices that do not present themselves as traditional storage volumes.
