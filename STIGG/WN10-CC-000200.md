# 🛡️ STIG Remediation: WN10-CC-000200

**STIG ID:** WN10-CC-000200  
**Title:** Administrator accounts must not be enumerated during elevation  
**Severity:** Medium  
**Rule Version:** V1R20  
**Finding ID:** V-220700

---

## 📋 Description

Enumerating administrator accounts during privilege elevation can expose privileged user details and increase the risk of brute-force attacks. Disabling the display of administrator accounts enhances security by requiring users to enter valid credentials without hints or account listings.

---

## 🧰 Remediation Steps (Group Policy)

1. Press `Windows Key + R`, type `gpedit.msc`, and press Enter to launch the **Local Group Policy Editor**.
2. Navigate to:
   ```
   Computer Configuration
   └── Administrative Templates
       └── Windows Components
           └── Credential User Interface
   ```
3. Double-click on **Enumerate administrator accounts on elevation**.
4. Set the policy to **Disabled**.
5. Click **Apply**, then **OK**.

---

## 💻 Remediation via PowerShell (Registry Edit)

```powershell
# Ensure registry path exists
New-Item -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\CredUI" -Force

# Disable enumeration of administrator accounts during elevation
Set-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\CredUI" -Name "EnumerateAdministrators" -Type DWord -Value 0
```

---

## ✅ Verification

To confirm the setting is applied, run:

```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\CredUI"
```

Expected Output:
```
EnumerateAdministrators : 0
```
