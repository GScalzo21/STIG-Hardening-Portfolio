# ✅ STIG Remediation: WN10-00-000090 – Password Expiration

**STIG ID:** WN10-00-000090  
**Title:** Accounts must be configured to require password expiration  
**Status:** ⚠️ Audit Deprecated — Will be removed in a future update  

---

## 🔍 Purpose

Passwords that do not expire increase the risk of compromise over time. All active local accounts must be configured so that their passwords **do not** have the "Password never expires" option checked.

---

## 🛠️ Manual Remediation Steps

1. Open **Computer Management**:
   - Press `Windows + R`
   - Type `compmgmt.msc` and press **Enter**

2. In the left pane, navigate to:

System Tools > Local Users and Groups > Users


3. In the middle pane, double-click **each active account**.

4. In the account properties window:
- **Ensure** that the checkbox **"Password never expires"** is **unchecked**.
- Click **Apply**, then **OK**.

5. Repeat this process for **all active local user accounts**.

> ⚠️ Skip system accounts or disabled accounts unless specifically required.

---

## ✅ Verification

Reopen **each account** to confirm that:
- **"Password never expires" is unchecked** for all active users.

---

## 📌 Notes

- This audit is deprecated but still represents a good security practice.
- No scripts or command-line tools were used — changes were made manually via GUI.
