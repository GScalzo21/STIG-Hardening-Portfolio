# 🕒 STIG Remediation: WN10-UR-000035  
**Title:** The "Change the system time" user right must only be assigned to Administrators, LOCAL SERVICE, and NT SERVICE\autotimesvc  
**Severity:** Medium  
**Status:** ✅ Compliant  
**Audit Status:** Manual Check  
**STIG ID:** WN10-UR-000035  
**Vuln ID:** V-220825  
**SRG ID:** SRG-OS-000121-GPOS-00062  
**CCI:** CCI-000879  

---

## 🔍 Finding

Verify that only the following accounts are assigned the **"Change the system time"** user right:

- `Administrators`
- `LOCAL SERVICE`
- `NT SERVICE\autotimesvc` *(Added by Microsoft in v1909 and later)*

Any additional entries (such as `Users`, `Everyone`, or custom service accounts) constitute a **finding**.

---

## 🛠️ Manual Remediation

1. Open **Local Security Policy** (`secpol.msc`)
2. Navigate to:  
   `Security Settings` → `Local Policies` → `User Rights Assignment`
3. Double-click **Change the system time**
4. Ensure **only** the following are listed:
   - `Administrators`
   - `LOCAL SERVICE`
   - `NT SERVICE\autotimesvc`
5. If other entries exist:
   - Select the entry and click **Remove**
6. If any required entry is missing:
   - Click **Add User or Group...**
   - Type each exactly as shown:
     - `Administrators`
     - `LOCAL SERVICE`
     - `NT SERVICE\autotimesvc`
   - Click **OK** after each entry
7. Click **Apply**, then **OK**
