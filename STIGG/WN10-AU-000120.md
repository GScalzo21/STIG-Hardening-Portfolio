# WN10-AU-000120: Audit IPSec Driver Failures

> **Status:** ✅ Active  
> **Audit Status:** Manual Check  

## Information  
Auditing IPSec driver failures ensures that issues related to the IPsec protocol — which provides secure network communications — are logged. These logs can reveal misconfigurations, dropped packets, or blocked traffic that may indicate attacks or transport-level errors.

## Solution  
Configure **Audit IPSec Driver** to log **Failure** events.

## Policy Path  

Computer Configuration
└─ Windows Settings
└─ Security Settings
└─ Advanced Audit Policy Configuration
└─ System Audit Policies
└─ System
└─ Audit IPSec Driver


## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to the IPSec Audit Policy**  
   - Expand:
     ```
     Computer Configuration
     └─ Windows Settings
        └─ Security Settings
           └─ Advanced Audit Policy Configuration
              └─ System Audit Policies
                 └─ System
     ```

3. **Locate “Audit IPSec Driver”**  
   - In the **System** folder, find **Audit IPSec Driver**.

4. **Configure the Policy**  
   - Double‑click **Audit IPSec Driver**.  
   - Check **Failure**.  
   - Click **OK**.

5. **Apply and Refresh**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

6. **Verify Configuration**  
   - In **PowerShell**, run:
     ```powershell
     AuditPol /get /subcategory:"IPsec Driver"
     ```
   - Ensure the output shows:
     ```
     IPsec Driver    Failure
     ```

## Summary  
- **gpedit.msc** → Advanced Audit Policy Configuration → System → Audit IPSec Driver  
- **Set** to audit **Failure** events  
- **Apply** with `gpupdate /force`  
- **Verify** using `AuditPol`
