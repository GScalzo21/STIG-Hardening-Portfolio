# 📦 STIG Remediation: WN10-AU-000090  
**Title:** The System Must Be Configured to Audit Object Access - Removable Storage Successes  
**Severity:** Medium  
**Status:** ✅ Compliant  
**Audit Status:** Manual Check  
**STIG ID:** WN10-AU-000090  
**Vuln ID:** V-220744  
**SRG ID:** SRG-OS-000472-GPOS-00217  
**CCI:** CCI-000133  

---

## 🔍 Finding

Auditing object access for **removable media** captures events when files or objects on devices like USB drives are accessed. This is critical for detecting unauthorized data transfers or suspicious behavior related to portable storage.

---

## 🛠️ Remediation Steps

1. Press `Win + R`, type `gpedit.msc`, and press **Enter**.
2. In the **Local Group Policy Editor**, navigate to:  

Computer Configuration >>
Windows Settings >>
Security Settings >>
Advanced Audit Policy Configuration >>
System Audit Policies >>
Object Access

3. Double-click **Audit Removable Storage**.
4. Check the box for **Configure the following audit events**.
5. Select **Success**.
6. Click **Apply**, then **OK**.

---

## ✅ Verification

1. Return to:

System Audit Policies >> Object Access >> Audit Removable Storage

2. Ensure only **Success** is selected.

Alternatively, verify with PowerShell:
```powershell
AuditPol /get /category:"Object Access"

Look for:

Removable Storage     Success
🔁 Reboot Required?

❌ Not required
✅ Run this to apply the policy immediately:

gpupdate /force

📌 Notes

Logging successful access to removable storage is essential for incident response and auditing.
Failure to enable this could result in missed detection of data exfiltration or misuse of portable media.
