# 🔒 STIG Remediation: WN10-SO-000095

**Title:** The Smart Card removal option must be configured to Force Logoff or Lock Workstation  
**Severity:** Medium  
**Status:** ⚠️ Deprecated  
**Audit Status:** Manual Check  
**STIG ID:** WN10-SO-000095  
**Vuln ID:** V-220675  
**SRG ID:** SRG-OS-000480-GPOS-00225  
**CCI:** CCI-000133  

---

## ⚠️ Notice: Audit Deprecated

This setting is **deprecated** and will be removed in a future **Windows update**.  
However, current systems should still apply it if possible to maintain **security best practices**.

---

## 🔍 Finding

**Unattended systems** are vulnerable to **unauthorized access**.  

Configuring the system to either:

- **Lock Workstation**, or  
- **Force Logoff**  

when a smart card is removed helps secure the device by **preventing access** if the user leaves without locking.

---

## 🛠️ Manual Configuration

### Open Local Group Policy Editor

- Press `Win + R`, type `gpedit.msc`, and press **Enter**.

---

### Navigate to:

```text
Computer Configuration
└─ Windows Settings
   └─ Security Settings
      └─ Local Policies
         └─ Security Options
```

## 🛠️ Configure the Following Setting

- Locate and double-click:  
  **Interactive logon: Smart card removal behavior**

- Select one of the following options:

    - **Lock Workstation**  
    - **Force Logoff**

- Click **Apply**, then **OK**.

---

## ✅ Verification

You can verify this setting via **Local Security Policy** or by checking the registry key:

```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" -Name ScRemoveOption
```
Expected Values:
```
1 = Lock Workstation
2 = Force Logoff
❌ If the value is missing or not set to one of these values — the setting is not properly configured.
```
---

📌 Notes

Enabling this setting protects against unauthorized access to unattended machines using smart cards.
The setting is deprecated, but may still be necessary on legacy systems.
Plan for eventual removal or replacement in future Windows releases.
