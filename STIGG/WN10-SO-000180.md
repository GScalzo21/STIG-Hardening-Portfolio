# 🚫 STIG Remediation: WN10-SO-000180  
**Title:** NTLM Must Be Prevented from Falling Back to a Null Session  
**Severity:** Medium  
**Status:** ✅ Compliant  
**Audit Status:** Manual Check  
**STIG ID:** WN10-SO-000180  
**Vuln ID:** V-220967  
**SRG ID:** SRG-OS-000480-GPOS-00227  
**CCI:** CCI-000366  

---

## 🔍 Finding

NTLM fallback to a NULL session can allow unauthorized access. This setting must be explicitly disabled to maintain secure authentication.

---

## 🛠️ Manual Remediation

1. Open **Local Security Policy**:
   - Press `Windows + R`, type `secpol.msc`, and press Enter.

2. Navigate to:
Local Policies >> Security Options


3. Find the policy:

Network security: Allow LocalSystem NULL session fallback


4. Double-click it and set it to:
Disabled


5. Click **Apply**, then **OK**.

---

## ✅ Verification

Reopen **secpol.msc** and confirm the policy:
- **Network security: Allow LocalSystem NULL session fallback** = **Disabled**

---

## 🔁 Reboot Required?

- ❌ Not usually, but recommended to ensure policy is fully applied.

---

## 📌 Notes

- This policy helps prevent NTLM from defaulting to insecure fallback methods such as null sessions.
- Applies to Windows 10 systems.
