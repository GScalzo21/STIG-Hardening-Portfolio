# WN10-CC-000365: Prevent Windows apps from being activated by voice while the system is locked

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Allowing Windows apps to be activated by voice from the lock screen could allow for unauthorized use. Requiring logon ensures the apps are only used by authorized personnel.

## Solution  
Configure the policy value for:


Computer Configuration
├─ Administrative Templates
└─ Windows Components
└─ App Privacy
└─ “Let Windows apps activate with voice while the system is locked”

to **Enabled**, with **“Default for all apps:”** set to **Force Deny**.

> **Note:**  
> If **“Let Windows apps activate with voice”** (same path above) is already set to **Enabled** with **Default for all apps: Force Deny**, then this requirement is **Not Applicable**.

---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to App Privacy Settings**  
   - In the left pane, expand:
     ```
     Computer Configuration
     └─ Administrative Templates
        └─ Windows Components
           └─ App Privacy
     ```

3. **Locate the “While Locked” Policy**  
   - Find **“Let Windows apps activate with voice while the system is locked”**.

4. **Configure the Policy**  
   - Double‑click the setting.  
   - Select **Enabled**.  
   - Under **Options**, set **Default for all apps:** to **Force Deny**.  
   - Click **OK**.

5. **(Optional) Verify N/A Condition**  
   - If you’d rather disable all voice activation globally, locate **“Let Windows apps activate with voice”** (same folder).  
   - Enable it and set **Default for all apps:** to **Force Deny**.  
   - In this case, the **“while the system is locked”** policy becomes Not Applicable.

6. **Apply and Refresh Policies**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

7. **Test the Configuration**  
   - Lock the workstation (`Win + L`) and attempt to use “Hey Cortana” or voice‑activated features.  
   - Voice activation should be blocked until you log in.

---

## Summary of Steps

1. **gpedit.msc** → Administrative Templates → Windows Components → App Privacy  
2. **Enable** “Let Windows apps activate with voice while the system is locked”  
3. Set **Default for all apps: Force Deny**  
4. **gpupdate /force**  
5. Test by locking the machine and issuing a voice command
