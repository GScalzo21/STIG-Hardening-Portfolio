# WN10-CC-000370: The convenience PIN for Windows 10 must be disabled

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Domain users should not be allowed to sign in with a convenience PIN, as this can weaken authentication (e.g., “Password Stuffer” attacks). Disabling PIN sign‑in forces the use of stronger credentials.

## Solution  
Disable the convenience PIN sign‑in by configuring the following Group Policy:

Computer Configuration
└─ Administrative Templates
└─ System
└─ Logon
└─ “Turn on convenience PIN sign‑in” → Disabled


---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to the PIN Policy**  
   - Expand in the left pane:
     ```
     Computer Configuration
     └─ Administrative Templates
        └─ System
           └─ Logon
     ```

3. **Locate “Turn on convenience PIN sign‑in”**  
   - In the **Logon** folder, find the policy named **Turn on convenience PIN sign‑in**.

4. **Disable the Policy**  
   - Double‑click the policy.  
   - Select **Disabled**.  
   - Click **OK** to apply.

5. **Enforce the Change**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

6. **Verify**  
   - Attempt to set up a Windows Hello PIN under **Settings → Accounts → Sign‑in options**.  
   - The option to create or use a PIN should be grayed‑out or unavailable.

---

## Summary of Steps

1. **gpedit.msc** → Administrative Templates → System → Logon  
2. **Disable** “Turn on convenience PIN sign‑in”  
3. **gpupdate /force**  
4. **Verify** PIN creation is blocked
