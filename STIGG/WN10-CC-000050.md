# WN10-CC-000050: Hardened UNC Paths – Require Mutual Authentication & Integrity

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Hardened UNC Paths apply additional security checks before allowing access to network shares, helping prevent tampering or spoofing. By configuring SYSVOL and NETLOGON shares to require mutual authentication and integrity, you ensure that both client and server authenticate each other and that communications are not altered in transit.

## Solution  
Enable and configure the **Hardened UNC Paths** policy with the following entries:

| Value Name        | Value                                                         |
|-------------------|---------------------------------------------------------------|
| `\\*\SYSVOL`      | `RequireMutualAuthentication=1, RequireIntegrity=1`           |
| `\\*\NETLOGON`    | `RequireMutualAuthentication=1, RequireIntegrity=1`           |

### Policy Path  
```text
Computer Configuration
└─ Administrative Templates
   └─ Network
      └─ Network Provider
         └─ “Hardened UNC Paths”
```

# Step‑by‑Step Remediation

Open Group Policy Editor
Press Win + R, type gpedit.msc, and press Enter.
Navigate to the Policy


Computer Configuration
└─ Administrative Templates
   └─ Network
      └─ Network Provider

Select Hardened UNC Paths.
Enable the Policy

Double‑click Hardened UNC Paths.
Select Enabled.

Click the Show… button under Hardened UNC Paths to open the value dialog.
Add Required Entries

In the Show Contents dialog, add two rows:
Value Name	  Value
\\*\SYSVOL	RequireMutualAuthentication=1, RequireIntegrity=1
\\*\NETLOGON	RequireMutualAuthentication=1, RequireIntegrity=1

Click OK to close Show Contents, then OK to close the policy dialog.
Apply the Change


Open an elevated Command Prompt and run:
gpupdate /force
Verify Configuration

Use PowerShell to query the registry or test access:
Get-ItemProperty -Path "HKLM:\Software\Policies\Microsoft\Windows\NetworkProvider\HardenedPaths"
Confirm entries for \\*\SYSVOL and \\*\NETLOGON with the correct settings.
