# Remediation for WN10-SO-000250: User Account Control (UAC) Prompt for Administrators

## Step 1: Identify the STIG Requirement
- **STIG ID**: WN10-SO-000250
- **Requirement**: User Account Control (UAC) must, at minimum, prompt administrators for consent on the secure desktop.
- **STIG Description**: UAC is a security feature that prevents unauthorized elevation of privileges. The behavior of the elevation prompt must be configured to ensure that administrators are prompted on the secure desktop for elevated tasks.

## Step 2: Review the Current Configuration
- The relevant policy is located under **Computer Configuration > Windows Settings > Security Settings > Local Policies > Security Options**.
- The policy name is: **User Account Control: Behavior of the elevation prompt for administrators in Admin Approval Mode**.
- You need to check if the setting is configured to prompt administrators for consent on the secure desktop.

## Step 3: Open Group Policy Editor
1. Press `Win + R` to open the Run dialog.
2. Type `gpedit.msc` and press Enter to open the Group Policy Editor.

## Step 4: Navigate to the Policy
1. In the Group Policy Editor, expand the following nodes:
    - **Computer Configuration**
    - **Windows Settings**
    - **Security Settings**
    - **Local Policies**
    - **Security Options**
    
2. Scroll down and find the policy: **User Account Control: Behavior of the elevation prompt for administrators in Admin Approval Mode**.

## Step 5: Modify the Policy Setting
1. Double-click on the policy: **User Account Control: Behavior of the elevation prompt for administrators in Admin Approval Mode**.
2. In the window that opens, select the option: **Prompt for consent on the secure desktop**.
3. Click **OK** to apply the changes.

## Step 6: Verify the Change
- Ensure the policy is correctly configured by checking the Group Policy settings or using PowerShell to confirm:
    - You can query the setting using the following PowerShell command:

```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\System" -Name ConsentPromptBehaviorAdmin

The output should show the value 5 for the Prompt for consent on the secure desktop option.
```
Step 7: Test the Configuration

Test the change by attempting to run a program or task that requires administrative privileges. You should be prompted for consent on the secure desktop.
