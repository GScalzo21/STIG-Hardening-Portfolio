# Remediation for STIG ID: WN10-SO-000255

## Title:
Deny elevation requests for standard users (UAC)

## Description:
User Account Control must be configured to automatically deny elevation requests from standard users. This prevents them from attempting privileged actions without admin credentials.

## Remediation Steps (Using Local Group Policy):

1. Press `Windows + R`, type `gpedit.msc`, and press Enter.
2. Navigate to:

Computer Configuration > Windows Settings > Security Settings > Local Policies > Security Options

3. Locate the setting:
**"User Account Control: Behavior of the elevation prompt for standard users"**
4. Set the value to:
**Automatically deny elevation requests**
5. Click **Apply**, then **OK**.

## Notes:
This disables the UAC prompt for standard users and prevents privilege escalation unless administrative credentials are supplied.
