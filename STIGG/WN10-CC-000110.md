# WN10-CC-000110: Prevent Printing over HTTP

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Allowing printing over HTTP can expose sensitive data and enable uncontrolled updates via Internet printers. Disabling this capability ensures that clients cannot send print jobs over HTTP, limiting printing to secure protocols.

## Solution  
Enable the **Turn off printing over HTTP** policy.

### Policy Path  
```text
Computer Configuration
└─ Administrative Templates
   └─ System
      └─ Internet Communication Management
         └─ Internet Communication settings
            └─ “Turn off printing over HTTP”

Apply and Refresh
Open an elevated Command Prompt and run:
gpupdate /force
