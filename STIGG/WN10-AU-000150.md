# WN10-AU-000150: Audit Security System Extension Successes

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Maintaining an audit trail of system activity is crucial for identifying configuration errors, troubleshooting disruptions, and detecting potential compromises.  
The **Security System Extension** subcategory records events when extension code is loaded by the security subsystem, providing visibility into drivers or modules that integrate with Windows security components.

## Solution  
Enable success auditing for Security System Extension by configuring the advanced audit policy:


---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to Advanced Audit Policies**  
   - Expand:
     ```
     Computer Configuration
     └─ Windows Settings
        └─ Security Settings
           └─ Advanced Audit Policy Configuration
              └─ System Audit Policies
                 └─ System
     ```

3. **Locate “Audit Security System Extension”**  
   - In the **System** folder, find **Audit Security System Extension**.

4. **Enable Success Auditing**  
   - Double‑click the setting.  
   - Check **Success** (uncheck **Failure** if selected).  
   - Click **OK**.

5. **Apply Policy Changes**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

6. **Verify Configuration**  
   - In an elevated PowerShell prompt, run:
     ```powershell
     auditpol /get /subcategory:"Security System Extension"
     ```
   - Confirm **Success** is listed under the “Audit Policy” for this subcategory.

---

## Summary of Steps

1. **gpedit.msc** → Windows Settings → Security Settings → Advanced Audit Policy Configuration  
2. **Enable** Success for “Audit Security System Extension”  
3. **gpupdate /force**  
4. **Verify** with `auditpol /get /subcategory:"Security System Extension"`
