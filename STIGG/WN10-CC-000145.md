# Remediation for STIG ID: WN10-CC-000145

## Title:
Prompt for password on resume from sleep (on battery)

## Description:
Users must be prompted for a password when resuming from sleep while on battery to ensure security in case of unattended portable devices.

## Remediation Steps (Using Local Group Policy):

1. Press `Windows + R`, type `gpedit.msc`, and press Enter.
2. Navigate to:

Computer Configuration > Administrative Templates > System > Power Management > Sleep Settings

3. Locate the setting:
**"Require a password when a computer wakes (on battery)"**
4. Double-click the policy and set it to **Enabled**.
5. Click **Apply**, then **OK**.

## Notes:
This enforces password protection when a laptop wakes from sleep while not plugged in, as required by the STIG.
