# WN10-SO-000100: The Windows SMB client must be configured to always perform SMB packet signing.

## Audit Status
- **Warning!** Audit Deprecated  
- This audit has been deprecated and will be removed in a future update.

## Information
The Server Message Block (SMB) protocol is the basis for many network operations in Windows environments. Digitally signed SMB packets are essential for preventing man-in-the-middle (MITM) attacks. By enforcing SMB packet signing, the SMB client ensures it only communicates with SMB servers that also perform SMB packet signing. This enhances network security by verifying the integrity and authenticity of network communications.

## Solution
To remediate this control, you need to configure the SMB client to always sign packets. This is done by enabling the **Microsoft network client: Digitally sign communications (always)** policy.

### Steps to Configure the SMB Client for Always Perform SMB Packet Signing:

1. **Open Group Policy Editor:**
   - Press **Windows + R**, type `gpedit.msc`, and press **Enter** to open the Group Policy Editor.

2. **Navigate to the Policy Setting:**
   - Go to **Computer Configuration** → **Windows Settings** → **Security Settings** → **Local Policies** → **Security Options**.

3. **Locate the Setting:**
   - Find the policy named: **Microsoft network client: Digitally sign communications (always)**.

4. **Enable the Policy:**
   - Double-click on the policy and set it to **Enabled**.
   - Click **OK** to apply the change.

5. **Force Group Policy Update:**
   - Open **Command Prompt** as Administrator and run the following command to apply the policy immediately:
     ```cmd
     gpupdate /force
     ```

6. **Verify the Configuration:**
   - Open **PowerShell** and run the following command to verify that SMB packet signing is enabled:
     ```powershell
     Get-SmbClientConfiguration | Select EnableSecuritySignature
     ```
   - Ensure the output shows **True**. If it does, the remediation has been successfully applied.

## Additional Notes:
- This setting ensures that SMB clients will only communicate with servers that also support SMB packet signing.
- Enabling this policy is crucial for protecting against network-based attacks, such as MITM attacks, and helps ensure the integrity and authenticity of SMB communications.
- This policy is part of the **Windows Security Configuration Guide** to help maintain a secure network environment.
