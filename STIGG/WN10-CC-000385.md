# 🛡️ STIG Remediation: WN10-CC-000385

**STIG ID:** WN10-CC-000385  
**Title:** Windows Ink Workspace must be configured to disallow access above the lock  
**Severity:** Medium  
**Rule Version:** V1R20  
**Finding ID:** V-220732

---

## 📋 Description

Allowing Windows Ink Workspace access above the lock screen may expose sensitive data or allow unauthorized user interaction while the system is locked. To ensure compliance with Windows 10 security guidelines, Windows Ink must either be disabled or configured to disallow access from the lock screen.

---

## 🧰 Remediation Steps (Group Policy)

1. Open **Local Group Policy Editor**: Press `Windows Key + R`, type `gpedit.msc`, and hit Enter.
2. Navigate to the following location:
   ```
   Computer Configuration
   └── Administrative Templates
       └── Windows Components
           └── Windows Ink Workspace
   ```
3. Locate and double-click on **Allow Windows Ink Workspace**.
4. Set the policy to **Enabled**.
5. Under **Options**, choose: **On, but disallow access above lock**.
6. Click **Apply**, then **OK** to enforce the policy.

---

## 💻 Remediation via PowerShell (Registry Edit)

```powershell
# Ensure the registry path exists
New-Item -Path "HKLM:\SOFTWARE\Policies\Microsoft\WindowsInkWorkspace" -Force

# Set the required values
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\WindowsInkWorkspace" -Name "AllowWindowsInkWorkspace" -Type DWord -Value 1
Set-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\WindowsInkWorkspace" -Name "AllowAboveLock" -Type DWord -Value 0
```

**Note:**  
- `AllowWindowsInkWorkspace = 1` enables the workspace.  
- `AllowAboveLock = 0` disallows access when the device is locked.

---

## ✅ Verification

To confirm the values are set correctly, run:

```powershell
Get-ItemProperty -Path "HKLM:\SOFTWARE\Policies\Microsoft\WindowsInkWorkspace"
```

Expected Output:
```
AllowWindowsInkWorkspace : 1
AllowAboveLock           : 0
```
