# WN10-AC-000035 - Passwords Must Be At Least 14 Characters

## Description
Windows 10 systems must enforce a minimum password length of **14 characters**.  
Longer passwords increase security by making it harder for attackers to guess or brute-force passwords.

## Why it matters
Using passwords with at least 14 characters strengthens account security and reduces the risk of unauthorized access due to weak or easily guessable passwords. This is especially important for protecting sensitive systems and data.

## How to fix

1. Open **Group Policy Editor** (`gpedit.msc`).
2. Navigate to:  
   `Computer Configuration → Windows Settings → Security Settings → Account Policies → Password Policy`
3. Double-click **Minimum password length**.
4. Set the value to **14** or more characters.
5. Click **OK** and close the editor.

## Verification
Run this command in PowerShell or Command Prompt to check the current minimum password length:

```powershell
net accounts | findstr /C:"Minimum password length"

Ensure the output shows 14 or higher.
