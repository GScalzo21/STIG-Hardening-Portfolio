# WN10-CC-000190: Disable AutoPlay for All Drives

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Autoplay can automatically execute media content when drives are inserted, potentially running malicious code. By disabling AutoPlay on all drives, you prevent any automatic execution of media content.

## Solution  
Enable the **Turn off AutoPlay** policy for **All Drives**.

### Policy Path  


---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to AutoPlay Policies**  
   - Expand:
     ```text
     Computer Configuration
     └─ Administrative Templates
        └─ Windows Components
           └─ AutoPlay Policies
     ```
   - Select **Turn off AutoPlay**.

3. **Configure the Policy**  
   - Double‑click **Turn off AutoPlay**.  
   - Select **Enabled**.  
   - Under **Options**, choose **All drives** from the dropdown.  
   - Click **OK**.

4. **Apply and Refresh**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

5. **Verify Configuration**  
   - In **Registry Editor** (`regedit`), navigate to:
     ```
     HKLM\Software\Policies\Microsoft\Windows\Explorer
     ```
   - Ensure the `NoAutorun` DWORD exists and is set to:
     - `1` (All drives)

---

## Summary of Steps

1. **gpedit.msc** → Administrative Templates → Windows Components → AutoPlay Policies  
2. **Enable** “Turn off AutoPlay”  
3. Set **Options:** to **All drives**  
4. **gpupdate /force**  
5. **Verify** registry `NoAutorun = 1`
