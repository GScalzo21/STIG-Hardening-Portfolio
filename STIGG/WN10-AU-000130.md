# WN10-AU-000130 - Audit System: Other System Events (Success)

## Description
Windows 10 must be configured to audit **System → Other System Events** successes.  
This setting ensures that successful system-level events that don’t fit into specific audit categories are logged. These events help in monitoring system behavior and troubleshooting.

## Why it matters
Auditing Other System Events provides visibility into important system activities such as driver loads, system time changes, and other system-level operations. This information is valuable for detecting unauthorized changes and supporting forensic investigations.

## How to fix

1. Open **Group Policy Editor** (`gpedit.msc`).
2. Navigate to:  
   `Computer Configuration → Windows Settings → Security Settings → Advanced Audit Policy Configuration → System Audit Policies → System`
3. Locate **Other System Events**.
4. Set it to **Success** (enable auditing for successful events).
5. Apply the changes and close the editor.

## Verification
Run the following command to check if the audit policy is enabled:

```powershell
auditpol /get /category:"System"

Look for Other System Events set to Success.
