# WN10-AC-000020: Enforce Password History (24 Passwords Remembered)

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Requiring users to reuse a unique password prevents them from circumventing periodic password changes. The default value for Windows domain systems is 24; DoD mandates this value for all Windows systems.

## Solution  
Configure **Enforce password history** to **24** remembered passwords.

## Policy Path  

Computer Configuration
└─ Windows Settings
└─ Security Settings
└─ Account Policies
└─ Password Policy
└─ “Enforce password history”


## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to Password Policy**  
   - Expand:
     ```
     Computer Configuration
     └─ Windows Settings
        └─ Security Settings
           └─ Account Policies
              └─ Password Policy
     ```

3. **Locate “Enforce password history”**  
   - In the **Password Policy** folder, find **Enforce password history**.

4. **Configure the Policy**  
   - Double‑click **Enforce password history**.  
   - Set the value to **24**.  
   - Click **OK**.

5. **Apply and Refresh**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

6. **Verify Configuration**  
   - In **Command Prompt** or **PowerShell**, run:
     ```powershell
     secedit /export /areas SECURITYPOLICY /cfg C:\secconfig.cfg
     Select-String -Path C:\secconfig.cfg -Pattern "PasswordHistorySize"
     ```
   - Ensure `PasswordHistorySize = 24`.

## Summary  
- **gpedit.msc** → Security Settings → Account Policies → Password Policy  
- **Set** “Enforce password history” to **24**  
- **gpupdate /force**  
- **Verify** via `secedit` export
