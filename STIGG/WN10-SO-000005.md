# ✅ STIG Remediation: WN10-SO-000005  
**Title:** The built-in administrator account must be disabled  
**Category:** Security Options  
**Path:**  
Computer Configuration >> Windows Settings >> Security Settings >> Local Policies >> Security Options >>  
**Policy:** Accounts: Administrator account status  
**Configured Value:** Disabled  

---

## 🔧 Remediation Steps

1. Open **Local Group Policy Editor** (`gpedit.msc`)
2. Navigate to:  
   `Computer Configuration` → `Windows Settings` → `Security Settings` → `Local Policies` → `Security Options`
3. Find the policy **Accounts: Administrator account status**
4. Set the policy to **Disabled**
5. Click **Apply** and **OK**
6. Close the Group Policy Editor

---

## 🔎 Validation

To verify the setting was applied correctly, open **PowerShell as Administrator** and run:

```powershell
Get-LocalUser -Name "Administrator" | Select-Object Name, Enabled
```

### ✅ Expected Output:
Name Enabled


---

### 📌 Notes
Disabling the built-in Administrator account helps reduce the attack surface by preventing unauthorized access using a well-known default account. This is especially critical for systems exposed to internal or external networks.
