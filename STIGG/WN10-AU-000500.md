## Remediation for Windows 10 STIG Finding: WN10-AU-000500

To remediate the Windows 10 Security Technical Implementation Guide (STIG) finding **WN10-AU-000500**, which requires the Application event log size to be configured to **32768 KB or greater**, you need to adjust the maximum size of the Application event log.

### Step-by-Step Guide:

#### 1. Using Group Policy (Recommended for Domain-joined Systems):

- **Open Group Policy Management:**
  - Press `Windows Key + R`, type `gpmc.msc`, and press Enter.

- **Navigate to the relevant Group Policy Object:**
  - Either edit an existing GPO or create a new one that applies to the target computers.

- **Edit the Group Policy Object:**
  - Right-click the GPO and select **Edit**.

- **Locate the Policy Setting:**
  - Go to:  
    `Computer Configuration > Policies > Administrative Templates > Windows Components > Event Log Service > Application`

- **Configure the "Specify the maximum log file size (KB)" policy:**
  - Double-click the policy setting.
  - Set it to **Enabled**.
  - Enter **32768** or greater for the **Maximum Log Size (KB)**.
  - Click **OK** to save the changes.
