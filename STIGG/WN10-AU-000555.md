# 🛡️ STIG Remediation: WN10-AU-000555

**Title:** Windows 10 must be configured to audit Other Policy Change Events failures  
**Severity:** Medium  
**Status:** ✅ Compliant (if properly configured)  
**Audit Status:** Manual Check  
**STIG ID:** WN10-AU-000555  
**Vuln ID:** V-220934  
**SRG ID:** SRG-OS-000327-GPOS-00127  
**CCI:** CCI-002234  

---

## 🔍 Finding

Verify that **Other Policy Change Events** are audited for **Failure**.

This audit policy tracks:

- Changes to **EFS Data Recovery Agent** policy  
- **Windows Filtering Platform** filter changes  
- **Local Group Policy Security** policy setting updates  
- **Central Access Policy** changes  
- **CNG (Cryptographic Next Generation)** troubleshooting events  

> ⚠️ **Note:** This setting has been marked as **deprecated** and will be removed in future Windows updates. It should still be enabled until officially retired to meet compliance.

---

## 🛠️ Manual Configuration

**Open Local Group Policy Editor:**  
- Press `Win + R`, type `gpedit.msc`, press **Enter**

**Navigate to:**  

```text
Computer Configuration
└─ Windows Settings
   └─ Security Settings
      └─ Advanced Audit Policy Configuration
         └─ System Audit Policies
            └─ Policy Change
```

## 🛠️ Configure the Following Setting

- Double-click **Audit Other Policy Change Events**  
- Ensure **Failure** is checked  
  - ✔ **Failure**  
  - ✖ **Success** (unless Success is required by another control)  
- Click **Apply**, then **OK**
