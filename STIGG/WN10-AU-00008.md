# 📁 STIG Remediation: WN10-AU-000081

**STIG ID:** WN10-AU-000081  
**Title:** Audit File Share must be configured to capture Failure events  
**Severity:** Medium  
**Rule Version:** V1R20  
**Finding ID:** V-220669

---

## 📋 Description

Auditing file share access failure events is essential to identifying unauthorized access attempts to shared folders or resources. Failure events help administrators detect security risks and potential data breaches stemming from unsuccessful access attempts to shared file locations.

---

## 🧰 Remediation Steps (Group Policy)

1. Press `Windows Key + R`, type `gpedit.msc`, and hit Enter to launch the **Local Group Policy Editor**.
2. Navigate to:
   ```
   Computer Configuration
   └── Windows Settings
       └── Security Settings
           └── Advanced Audit Policy Configuration
               └── System Audit Policies
                   └── Object Access
   ```
3. Double-click on **Audit File Share**.
4. Check **Configure the following audit events**.
5. Select **Failure**.
6. Click **Apply**, then **OK**.

---

## 💻 Remediation via PowerShell

```powershell
# Enable auditing for File Share failures
AuditPol /set /subcategory:"File Share" /failure:enable
```

---

## ✅ Verification

To verify the policy is configured:

```powershell
AuditPol /get /subcategory:"File Share"
```

Expected Output:
```
System audit policy
Category/Subcategory                      Setting
Object Access
  File Share                              Failure
```
