# Remediation for STIG ID: WN10-SO-000245

## Title:
Enable Admin Approval Mode for built-in Administrator

## Description:
UAC must be enabled for the built-in Administrator account to ensure all admin-level changes go through the UAC consent process.

## Remediation Steps (Using Local Group Policy):

1. Press `Windows + R`, type `gpedit.msc`, and press Enter.
2. Navigate to:


Computer Configuration > Windows Settings > Security Settings > Local Policies > Security Options


3. Locate the setting:
**"User Account Control: Admin Approval Mode for the Built-in Administrator account"**
4. Set the value to:
**Enabled**
5. Click **Apply**, then **OK**.

## Notes:
This setting enforces the same UAC restrictions on the built-in Administrator as it would on other administrative users.
