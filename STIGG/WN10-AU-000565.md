# WN10-AU-000565: Audit Other Logon/Logoff Events Failures

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Maintaining a comprehensive audit trail of logon and logoff activity is critical for identifying configuration errors, troubleshooting service disruptions, and detecting potential compromises or attacks.  
The **Audit Other Logon/Logoff Events** setting generates events for non-standard logon/logoff activities, providing deeper visibility into user and system behavior.

## Solution  
Enable failure auditing for **Other Logon/Logoff Events** by configuring the advanced audit policy:

Computer Configuration
└─ Windows Settings
└─ Security Settings
└─ Advanced Audit Policy Configuration
└─ System Audit Policies
└─ Logon/Logoff
└─ “Audit Other Logon/Logoff Events” → Failure


---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to Advanced Audit Policies**  
   Expand:



3. **Locate “Audit Other Logon/Logoff Events”**  
In the **Logon/Logoff** folder, find **Audit Other Logon/Logoff Events**.

4. **Enable Failure Auditing**  
Double‑click the setting, check **Failure**, uncheck **Success**, and click **OK**.

5. **Apply the Policy**  
In an elevated Command Prompt, run:
```cmd
gpupdate /force


Verify Configuration

Open an elevated PowerShell prompt and run:
auditpol /get /subcategory:"Other Logon/Logoff Events"

Confirm that Failure appears under the “Audit Policy” for this subcategory.
