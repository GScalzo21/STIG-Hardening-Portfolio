# 🔐 STIG Remediation: Restrict 'Back up files and directories' User Right

**STIG ID:** WN10-UR-000030  
**Severity:** Medium  
**SRG:** SRG-OS-000080-GPOS-00048  
**CCI:** CCI-000213  
**Vuln ID:** V-XXXXX  
**Vulnerability Status:** ✅ Active  

---

## 📖 Overview

This STIG ensures that only **authorized users** — specifically the **Administrators** group — have the **"Back up files and directories"** user right.  
Misconfigured privileges can lead to **unauthorized access** to sensitive data by bypassing standard file and folder permissions.

---

## ⚠️ Why It Matters

Accounts with this right can **circumvent NTFS file system permissions**, potentially accessing or exfiltrating sensitive data.  
Limiting this capability:
- Reduces **insider threat risk**  
- Minimizes **lateral movement** by threat actors  

---

## 🔍 Check: User Rights Assignment

### Using GUI:

1. Open the **Local Security Policy** tool:  
    - Press `Win + R`, type `secpol.msc`, and press **Enter**.

2. Navigate to:

```text
Computer Configuration
└─ Windows Settings
   └─ Security Settings
      └─ Local Policies
         └─ User Rights Assignment
```

## 🔍 Check: User Rights Assignment

### Locate the Policy

- **Back up files and directories**

### Confirm it only includes:

- ✅ **Administrators**

❌ If any other groups or users (e.g., **Backup Operators**, **Users**) are listed — **this is a finding**.

---

```powershell
secedit /export /cfg C:\temp\sec.cfg
