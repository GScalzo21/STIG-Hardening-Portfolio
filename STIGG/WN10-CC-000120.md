# WN10-CC-000120: Hide Network Selection UI on the Logon Screen

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

---

## 🔍 Information  
Displaying the network selection UI on the Windows logon screen may allow unauthenticated users to connect the system to untrusted networks before login. This increases the risk of compromise. Disabling this interface helps protect the system until proper credentials are entered.

---

##  Solution  
**Disable** the network selection UI on the logon screen.

### Group Policy Path  
```text
Computer Configuration
└─ Administrative Templates
   └─ System
      └─ Logon
         └─ "Do not display network selection UI"
```

Configure Setting

Double-click → Set to Enabled → Click OK

Update Group Policy
Open Command Prompt (Admin) and run: gpupdate /force
