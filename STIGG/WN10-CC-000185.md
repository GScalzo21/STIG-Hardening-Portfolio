## 🛡️ STIG Remediation: Disable AutoRun Command Execution - WN10-CC-000185

---

## 🖥️ Environment Requirement

- Ensure you are working on a **Windows 10 system**, as this remediation applies specifically to **Windows 10 operating systems**.

---

## 🛠️ Modify the Registry Key

You need to modify the registry key to **disable AutoRun**. The registry value `NoAutorun` needs to be set to `1` to disable AutoRun commands.

- **Registry Path:**  
  `HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer`

- **Value Name:** `NoAutorun`  
- **Value Data:** `1` *(This disables AutoRun)*

---

## 🔄 Update the Registry (PowerShell)

You can use the following PowerShell command to modify the registry:

```powershell
$registryPath = "HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Policies\Explorer"
$valueName = "NoAutorun"
$valueData = 1
```
# Ensure the registry path exists
if (-not (Test-Path $registryPath)) {
    New-Item -Path $registryPath -Force | Out-Null
}

# Set the registry key to disable AutoRun
Set-ItemProperty -Path $registryPath -Name $valueName -Value $valueData -Type DWord

Write-Host "AutoRun command execution disabled (NoAutorun = $valueData) at $registryPath"📝
