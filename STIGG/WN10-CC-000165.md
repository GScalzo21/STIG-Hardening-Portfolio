# WN10-CC-000165: Restrict Unauthenticated RPC Clients

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Restricting unauthenticated RPC clients prevents anonymous connections to the RPC server, mitigating the risk of unauthorized remote procedure calls.

## Solution  
Enable and configure the **Restrict Unauthenticated RPC clients** policy to **Authenticated**.

### Policy Path  

---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to the RPC Policy**  
   - Expand:
     ```text
     Computer Configuration
     └─ Administrative Templates
        └─ System
           └─ Remote Procedure Call
     ```
   - Select **Restrict Unauthenticated RPC clients**.

3. **Enable and Configure the Policy**  
   - Double‑click the policy.  
   - Set to **Enabled**.  
   - Under **Options**, choose **Authenticated**.  
   - Click **OK**.

4. **Apply and Refresh Policies**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

5. **Verify Configuration**  
   - In an elevated PowerShell prompt, run:
     ```powershell
     Get-ItemProperty -Path "HKLM:\Software\Policies\Microsoft\Windows\Rpc" -Name RestrictUnauthenticatedRpc
     ```
   - Confirm the `RestrictUnauthenticatedRpc` DWORD exists and is set to `1` (Authenticated).

---

## Summary of Steps

1. **gpedit.msc** → Administrative Templates → System → Remote Procedure Call  
2. **Enable** “Restrict Unauthenticated RPC clients” → **Authenticated**  
3. **gpupdate /force**  
4. **Verify** registry `RestrictUnauthenticatedRpc = 1`
