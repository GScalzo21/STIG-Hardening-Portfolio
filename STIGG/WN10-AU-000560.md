## 🔐 STIG Control: WN10-AU-000560

**Control Title**: Windows 10 must be configured to audit **Other Logon/Logoff Events - Success**  
**Severity**: CAT II  
**Status**: ⚠️ *Audit Deprecated* (This control will be removed in a future STIG update)  
**STIG Version**: Microsoft Windows 10 STIG v2r4  
**Rule ID**: SV-220924r569187_rule  
**Vuln ID**: V-220924  

---

### 📖 Description

Auditing "Other Logon/Logoff Events" captures events like session reconnections, disconnections, workstation locks/unlocks, and screensaver activity. These events are critical for tracking user activity, supporting threat detection, and performing post-incident forensics.

---

### 🛠️ Fix / Remediation

#### ✅ Group Policy Configuration

**Path:**


Computer Configuration >
Windows Settings >
Security Settings >
Advanced Audit Policy Configuration >
System Audit Policies >
Logon/Logoff >
Audit Other Logon/Logoff Events


**Required Setting:**

- [x] Success: **Enabled**
- [ ] Failure: Optional (enable based on org policy)

> Apply changes with:  
> `gpupdate /force`
