# WN10-AU-000570 - Audit Detailed File Share Failure Events

## Description
Windows 10 must be configured to **audit Detailed File Share failure events**.  
This setting ensures that any failed access to shared files or folders is logged for security monitoring and incident investigation.

## Why it matters
Auditing failed file share access helps identify unauthorized attempts to access shared resources and supports forensic investigations after an incident.

## How to fix

### Using Group Policy
1. Open **Group Policy Editor** (`gpedit.msc`).
2. Navigate to:  
   `Computer Configuration → Windows Settings → Security Settings → Advanced Audit Policy Configuration → Audit Policies → Object Access`
3. Locate **"Audit Detailed File Share"**.
4. Set it to **Failure** (or **Success and Failure** if required by your organization).
5. Click **Apply** and **OK**.

### Using Command Line
You can also use the following command to enable failure auditing:

```powershell
auditpol /set /subcategory:"Detailed File Share" /failure:enable

Verification

Run the following command to confirm the setting:

auditpol /get /subcategory:"Detailed File Share"
It should show:

Detailed File Share       Failure
