# WN10-CC-000205: Windows Telemetry must not be configured to Full

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Windows Telemetry can send system and usage data to Microsoft. Configuring it to **Full** risks exposing sensitive enterprise information.  
- **Security (0)**: Sends only telemetry data required for security (MSRT, Defender, telemetry client).  
- **Basic (1)**: Sends basic diagnostic and usage data—may be required for some Microsoft services.  
- **Enhanced (2)** and **Full (3)** send progressively more data and are not recommended for secure environments.

## Solution  
Configure the **Allow Telemetry** policy to one of the following values:
- **0 – Security [Enterprise Only]**  
- **1 – Basic**

### Policy Path  
```text
Computer Configuration
└─ Administrative Templates
   └─ Windows Components
      └─ Data Collection and Preview Builds
         └─ “Allow Telemetry”
```

## 🛠️ Step-by-Step Remediation

### Open Group Policy Editor

- Press `Win + R`, type `gpedit.msc`, and press **Enter**.

---

### Navigate to the Telemetry Policy

Expand:

```text
Computer Configuration
└─ Administrative Templates
   └─ Windows Components
      └─ Data Collection and Preview Builds
Locate "Allow Telemetry"
```

## 🛠️ Configure the Policy

### In the right pane:

- Find **Allow Telemetry**.

---

### Configure the Setting

1. Double-click **Allow Telemetry**.
2. Select: ✅ **Enabled**.
3. Under **Options**, choose:

    - `0` — **Security [Enterprise Only]** *(recommended for enterprises)*  
    - `1` — **Basic** *(if some Microsoft services require it)*

4. Click **OK**.

---

Open an **elevated Command Prompt** and run:
