# 🔐 STIG Remediation: WN10-AU-000110  
**Title:** Audit Sensitive Privilege Use Failures  
**Severity:** Medium  
**Status:** ✅ Compliant  
**Audit Status:** Manual Check  
**STIG ID:** WN10-AU-000110  
**Vuln ID:** V-220709  
**SRG ID:** SRG-OS-000327-GPOS-00127  
**CCI:** CCI-002234  

---

## 🔍 Finding

The system must be configured to **audit failures** when sensitive privileges are attempted. This helps in detecting unauthorized privilege use and potential compromise attempts.

---

## 🛠️ Remediation Steps

1. Press `Win + R`, type `secpol.msc`, and press **Enter**.
2. In the **Local Security Policy** window, navigate to:  

Computer Configuration >>
Windows Settings >>
Security Settings >>
Advanced Audit Policy Configuration >>
System Audit Policies >>
Privilege Use

3. Double-click **Audit Sensitive Privilege Use**.
4. In the properties window:
- Check **Failure**  
- (Optional: Check **Success** as well, if desired by policy)
5. Click **Apply**, then **OK**.

---

## ✅ Verification

To verify settings are correct:

1. Reopen `secpol.msc`.
2. Navigate to the same location:

Advanced Audit Policy Configuration >>
System Audit Policies >>
Privilege Use

3. Ensure **Failure** is selected for **Audit Sensitive Privilege Use**.
