# WN10-CC-000252: Disable Windows Game Recording and Broadcasting

> **Warning!** Audit Deprecated  
> This audit has been deprecated and will be removed in a future update.

## Information  
Windows Game Recording and Broadcasting can capture screenshots or video of applications, potentially exposing sensitive data. Disabling this feature prevents any unintended recording or broadcasting outside of approved gaming scenarios.

## Solution  
Disable the Windows Game Recording and Broadcasting feature by configuring the following Group Policy:


---

## Step‑by‑Step Remediation

1. **Open Group Policy Editor**  
   - Press `Win + R`, type `gpedit.msc`, and press **Enter**.

2. **Navigate to the Game Recording Policy**  
   - Expand:
     ```text
     Computer Configuration
     └─ Administrative Templates
        └─ Windows Components
           └─ Windows Game Recording and Broadcasting
     ```
   - Select **Enables or disables Windows Game Recording and Broadcasting**.

3. **Disable the Feature**  
   - Double‑click the policy.  
   - Select **Disabled**.  
   - Click **OK** to apply.

4. **Apply and Refresh**  
   - Open an elevated Command Prompt and run:
     ```cmd
     gpupdate /force
     ```

5. **Verify Configuration**  
   - Open **Registry Editor** (`regedit`) and navigate to:
     ```
     HKLM\Software\Policies\Microsoft\Windows\GameDVR
     ```
   - Confirm the DWORD `AllowGameDVR` is set to `0`.

---

## Summary of Steps

1. **gpedit.msc** → Administrative Templates → Windows Components → Windows Game Recording and Broadcasting  
2. **Disable** “Enables or disables Windows Game Recording and Broadcasting”  
3. **gpupdate /force**  
4. **Verify** registry `AllowGameDVR = 0`
