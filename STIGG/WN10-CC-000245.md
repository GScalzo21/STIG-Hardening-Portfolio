# WN10-CC-000245 - Disable Password Manager in Microsoft Edge

## Description
The password manager feature in the Microsoft Edge browser must be **disabled**.  
This prevents the browser from saving and autofilling passwords, reducing the risk of credential theft or accidental exposure.

## Why it matters
Disabling the password manager helps protect sensitive login credentials, especially on shared or enterprise-managed systems, by reducing the chances that saved passwords are stolen or misused.

## How to fix

### Using Group Policy Editor
1. Open **Group Policy Editor** (`gpedit.msc`).
2. Navigate to:  
   `Computer Configuration → Administrative Templates → Microsoft Edge → Password Manager`
3. Find **"Enable saving passwords to the password manager"**.
4. Set this policy to **Disabled**.
5. Click **OK** and close the editor.

### Using Registry Editor (if Group Policy is unavailable)
1. Open **Registry Editor** (`regedit`).
2. Navigate to:  
   `HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Edge`
3. Create or modify the DWORD value:  
   `PasswordManagerEnabled`  
   Set it to **0**.
4. Restart Edge or the computer to apply the changes.

## Verification
Check the setting in Edge by navigating to:  
`edge://settings/passwords`  
The option to save passwords should be grayed out or disabled.
