# 🚫 STIG Remediation: WN10-CC-000040  
**Title:** Insecure Logons to an SMB Server Must Be Disabled  
**Severity:** Medium  
**Status:** ✅ Compliant  
**Audit Status:** Manual Check  
**STIG ID:** WN10-CC-000040  
**Vuln ID:** V-220758  
**SRG ID:** SRG-OS-000480-GPOS-00227  
**CCI:** CCI-000366  

---

## 🔍 Finding

Insecure guest logons allow anonymous access to shared resources and can be exploited by attackers. This setting must be disabled to ensure all connections to SMB servers require authentication.

---

## 🛠️ Remediation Steps

1. Press `Win + R`, type `gpedit.msc`, and press **Enter**.
2. In the **Local Group Policy Editor**, navigate to:  

Computer Configuration >>
Administrative Templates >>
Network >>
Lanman Workstation

3. Double-click **Enable insecure guest logons**.
4. Set the policy to **Disabled**.
5. Click **Apply**, then **OK**.

---

## ✅ Verification

1. Reopen `gpedit.msc`.
2. Navigate back to:

Administrative Templates >>
Network >>
Lanman Workstation >>
Enable insecure guest logons

3. Confirm it is set to **Disabled**.

---

📌 Notes
